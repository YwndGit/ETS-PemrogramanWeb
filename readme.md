**Deskripsi Masalah:** 
Sebagai pedagang kecil, uang pribadi dan uang usaha saya sering tercampur di satu tempat. Aplikasi ini memisahkan kedua urusan tersebut agar keuntungan dari usaha bisa lebih jelas dan terlacak dengan memisahkan dompet "Pribadi" dan "Usaha".

## Fitur Wajib (W1–W6)
- [x] W1 — Form tambah transaksi (tanggal, jenis, kategori, nominal, catatan)
- [x] W2 — Daftar transaksi dirender dinamis, terbaru di atas, format Rupiah
- [x] W3 — Hapus transaksi dengan konfirmasi
- [x] W4 — Data persisten di localStorage
- [x] W5 — Ringkasan total pemasukan, pengeluaran, saldo (otomatis update)
- [ ] W6 — Validasi form (nominal > 0, field wajib, pesan error di halaman)

## Fitur Khas Persona

- [x] Bisa mencatat pindah dana antar dompet
